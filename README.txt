АВАРИЙНАЯ ВЕРСИЯ АУДИТА

1. В комплекте находится текущий исходный чек-лист:
   «Исходный_чек-лист.xlsx»
   Он используется как эталон структуры формы.

2. Приложение уже содержит встроенную копию этого чек-листа,
   поэтому первый запуск не требует интернета.

3. Чтобы изменить структуру новых аудитов:
   - отредактируйте «Исходный_чек-лист.xlsx»;
   - откройте приложение;
   - нажмите «Загрузить исходный чек-лист Excel»;
   - выберите изменённый .xlsx.
   Приложение построит форму по новому Excel.

4. Поддерживаются колонки первого листа:
   ПУНКТ | РАЗДЕЛ | Вес | Количество вариантов ответа

   Сейчас используются значения количества вариантов 3 или 5:
   3 = Да / Нет / Пропущено
   5 = Да / Нет / Значительные нарушения / Незначительные недочёты / Пропущено

5. Уже сохранённые аудиты не переделываются при смене чек-листа.
   Новый Excel применяется к новым аудитам.

6. Для выгрузки отчёта с изменённым Excel на сервере Google Apps Script
   должен быть установлен приложенный Code(3).gs. Он обратно совместим:
   обычная версия продолжает работать по серверному чек-листу,
   а аварийная версия передаёт снимок чек-листа из Excel.

7. Для полноценного офлайн-запуска как PWA нужен локальный HTTP(S)-сервер
   или размещение на доступном HTTPS-адресе. Сам index.html также можно
   открыть для проверки интерфейса, но Service Worker при file:// не работает.

Важно: внешний вид формы, логика ответов, фотографии и структура
отчётных файлов в аварийной версии сохранены; добавлен только механизм
локального источника чек-листа из Excel.


ОТЧЁТ ПО ФОРМЕ ОБРАЗЦА
В версии v3 PDF «Приложение к отчёту» формируется в формате образца: титульные реквизиты, разделы с процентом выполнения, проверяемый сотрудник и таблица «Пункт / Заметка / Результат». Фотографии размещаются в колонке «Заметка», ответы окрашиваются по типу, в конце выводится общий процент.
Имя проверяющего можно задать в app-config.js параметром CHECKER_NAME. Если оставить пустым, поле в отчёте останется пустым.


ВЕРСИЯ 4 — ХРАНЕНИЕ ФАЙЛОВ АУДИТА

После нажатия «ВЫГРУЗИТЬ ОТЧЁТ» отдельный PDF основного отчёта НЕ создаётся.
Создаётся только Excel-отчёт.

В Google Drive используется одна корневая папка:
«Отчёты по аудитам»

Для каждого аудита внутри неё создаётся отдельная папка с датой и временем
начала аудита и названием объекта. В неё сохраняются:
- Excel-отчёт;
- «Приложение к отчёту» в PDF по образцу пользователя;
- все фотографии аудита;
- файл черновика формы .audit, содержащий снимок формы на момент выгрузки
  и ссылки на сохранённые фотографии.

ZIP-пакет и отдельный PDF основного отчёта в новой версии не создаются.


ХРАНЕНИЕ ФОТОГРАФИЙ V4.1
Внутри папки каждого аудита создаётся отдельная подпапка "Фото". Основные файлы (Excel, приложение PDF, черновик) остаются в корне папки аудита.


ВАЖНО v5:
- Результаты сохраняются в Google Drive аккаунта, под которым выполняется Apps Script.
- Корневая папка: «Отчёты по аудитам».
- Внутри каждого аудита: Excel, Приложение PDF, .audit; фотографии — в подпапке «Фото».
- Основной PDF-отчёт больше не создаётся.
- Генератор приложения PDF не использует вложенные таблицы, чтобы избежать ошибки DocumentApp с дочерними элементами.
